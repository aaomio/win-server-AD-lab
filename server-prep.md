# Windows Server Preparation (Active Directory Lab)

This document describes the initial preparation required before installing Active Directory Domain Services (AD DS) on Windows Server.

All steps must be completed before continuing with domain configuration.

---

## 1. Required Downloads

The following software is required before starting the lab:

- [VMware Workstation Pro](https://www.vmware.com/products/desktop-hypervisor/workstation-and-fusion)

- [Windows Server 2022 Evaluation ISO](https://www.microsoft.com/en-us/evalcenter/download-windows-server-2022)

---

## 2. Windows Server Installation

Windows Server 2022 must be installed on a virtual machine.

Recommended:
- Standard Desktop Experience

After installation:
- Initial setup must be completed
- Administrator account must be configured
